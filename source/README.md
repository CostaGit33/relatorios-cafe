# Arquivos web editáveis do aplicativo

Esta pasta contém os arquivos `www/` extraídos do APK original e atualizados com as lojas solicitadas. Todas as lojas usam, por enquanto, os fornecedores e produtos padrão já existentes no aplicativo.

Para gerar um novo APK instalável, estes arquivos precisam voltar ao projeto Cordova/Android original e o pacote precisa ser recompilado e assinado.
